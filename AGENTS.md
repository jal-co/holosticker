# AGENTS.md

Guidance for AI agents (and humans in a hurry) working on Holosticker.

## Project

Holographic sticker studio: Vite + React + TypeScript + Tailwind CSS v4 +
shadcn/ui + three.js. Static build, deployed on Vercel (auto-deploys on push
to `main`).

- `src/lib/three-renderer.ts` - the whole 3D renderer: custom GLSL holofoil
  shader, distance-field die-cut, peel geometry, PNG/GIF/GLB exporters
- `src/lib/settings.ts` - `StickerSettings` interface, defaults, peel angles
- `src/components/Sidebar.tsx` - props editor
- `src/components/StickerCanvas.tsx` - main canvas + render loop
- `src/App.tsx` - state, upload, export orchestration, toolbar, dialogs
- `CHANGELOG.md` - generated by changesets; rendered by the in-app
  "What's new" dialog (`src/lib/changelog.ts` parses it at build time)

## Rules

1. Every user-facing change MUST include a changeset. Run `npx changeset`
   (or add a file under `.changeset/`) with a `minor` bump for features and
   `patch` for fixes. CI opens a "Version Packages" PR that bumps
   `package.json` and `CHANGELOG.md` - never edit those two by hand.
2. Do not hand-edit `CHANGELOG.md`. The in-app changelog dialog parses its
   changesets format (`## <version>` + bullets).
3. Verify before committing: `npx tsc -b` and `npm run build` must pass.
4. Conventional Commits (`feat:`, `fix:`, `chore:`, `docs:`, `style:`).
5. No AI attribution in commits, PRs, or code comments.
6. Match existing conventions: Tailwind utilities (no new styling systems),
   oklch for any new color values, shadcn/ui primitives from
   `src/components/ui/`.
7. Shader or geometry changes need a visual check in the browser
   (`npm run dev`), including the peel at several amounts/directions and an
   export.

## Commands

```sh
npm run dev        # dev server
npx tsc -b         # typecheck
npm run build      # production build
npx changeset      # record a change (required for features/fixes)
```
